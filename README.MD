
# Jira-GitHub Demo

This repository demonstrates how Jira issues can be linked to GitHub code changes.

## Objective

Track development work from a Jira issue to a Git commit.

## Workflow

1. Create a Jira issue.
2. Include the Jira issue key in the Git commit message.
3. Push the commit to GitHub.
4. Verify the linked commit in Jira.

## Example Commit Message

`DEMO-1 Add README for Jira GitHub integration`

Replace `DEMO-1` with your actual Jira issue key.

## Technologies

- Git
- GitHub
- Jira
